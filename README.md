# project12 — Голосовой помощник для Android

Мобильный голосовой помощник на **Android (Kotlin)**, который:

* работает в **фоновом режиме** (фоновый сервис с уведомлением);
* **постоянно слушает микрофон** и будится при звуке голоса;
* понимает голосовые команды на **русском языке** (распознавание через системный SpeechRecognizer — Google);
* отвечает голосом (TTS — синтез речи).

---

## 📱 Как скачать готовый .apk (без компьютера)

В репозитории настроена **автоматическая сборка APK через GitHub Actions**. Ты можешь скачать готовый установочный файл прямо с телефона, не устанавливая Android Studio.

### Способ 1 — Прямая ссылка из раздела Releases (самый простой)

1. Откройте страницу релизов репозитория с телефона:  
   `https://github.com/Aleksandr-pro/project12/releases`
2. В разделе **Assets** нажмите на файл **`app-debug.apk`** — скачается готовый установочный `.apk` (без архива).
3. Откройте скачанный `app-debug.apk` → **Установить** (при запросе разрешите установку из неизвестных источников для вашего браузера).

### Способ 2 — Из вкладки GitHub Actions (Artifacts)

1. Откройте репозиторий на GitHub (войдите в свой аккаунт GitHub в браузере):  
   `https://github.com/Aleksandr-pro/project12/actions`
2. Выберите workflow **"Build APK"** и откройте верхний успешный запуск (с зелёной галочкой ✅ на ветке `main`).  
   *(Если нужно запустить сборку заново вручную: нажмите **Run workflow** → ветка `main` → зелёная кнопка **Run workflow** и подождите ~2 минуты).*
3. Прокрутите страницу запуска вниз до блока **Artifacts** и нажмите **`app-debug-apk`** — скачается архив `app-debug-apk.zip`.
4. Откройте скачанный архив `app-debug-apk.zip` в «Файлах» / «Проводнике» на телефоне, **распакуйте** его (не переименовывайте!) и запустите находящийся внутри файл **`app-debug.apk`** → **Установить**.

## ⚠️ Важно перед установкой

* Это ** debug-версия ** приложения. Для работы нужны разрешения: микрофон, интернет, уведомления, работа в фоне.
* При первом запуске обязательно разрешите доступ к микрофону, иначе помощник не услышит голос.
* Минимальная версия Android: **7.0 (API 24)**.

## 🎤 Как пользоваться помощником

1. Откройте приложение «Помощник AI».
2. Нажмите **«Запустить помощника»**.
3. Появится уведомление «Помощник работает» — теперь он служит в фоне, даже если свернуть приложение.
4. Громко скажите ключевую фразу (помощник будится на любой звук выше порога).
5. Помощник ответит «Да, я слушаю» — называйте команду.

Доступные команды:
* «привет» / «здравствуй» — приветствие
* «как дела» — ответ о состоянии
* «время» — текущее время
* «дата» — текущая дата
* «погода» — информация (заглушка)
* «открой настройки» — откроет системные настройки
* «стоп» / «выключись» — завершить работу помощника

## 🔊 Настройка чувствительности к голосу

Порог срабатывания задаётся в файле `WakeWordMonitor.kt`:

```kotlin
private val energyThreshold: Double = 1200.0
```

* Если помощник **не слышит** голос — понизьте значение (например, до `800.0`).
* Если срабатывает на **любой шум** — повысьте (например, до `2000.0`).

После изменения нужно снова собрать APK через GitHub Actions.

## ❌ Возможные ошибки и как их исправить

| Ошибка | Причина | Решение |
|--------|---------|---------|
| «Приложение не установлено» | APK повреждён или не подходит под версию Android | Убедитесь, что на телефоне Android 7.0 или новее. Скачайте APK заново из Actions |
| «Установка неизвестных приложений заблокирована» | Защита системы Android | Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → ваш браузер → Разрешить |
| Помощник не реагирует на голос | Нет разрешения на микрофон или порог слишком высок | Дайте разрешение на микрофон в настройках телефона. Пoniзьте `energyThreshold` и пересоберите |
| Помощник не говорит (нет голоса) | TTS не инициализирован или нет языковых данных | На телефоне: Настройки → Язык и ввод → Текст в речь → установите русский язык |
| Распознавание не работает | Нет интернета | Включите мобильный интернет или Wi-Fi. Нужен доступ к серверам Google |
| Приложение закрывается при свертывании | Система убивает фоновый процесс | Настройки → Батарея → Помощник AI → «Не оптимизировать» |
| «Распознаватель речи недоступен» | На устройстве нет Google SpeechRecognizer | На некоторых прошивках (особенно китайских) нет сервисов Google |
| APK не устанавливается — «Не удалось 분석ровать пакет» | Файл не является настоящим APK | Скачивайте только из Artifacts в GitHub Actions, не переименовывайте ZIP |

## 🧩 Что ещё не реализовано (пропуски)

1. **Точная фраза пробуждения** — сейчас assistant будится на любой звук выше порога, а не на конкретное слово («Помощник»).
2. **Онлайн-погода** — команда «погода» показывает только заглушку.
3. **Офлайн-режим** — распознавание требует интернета.
4. **Настройка в приложении** — порог чувствительности меняется только в коде.
5. **Автозапуск при включении телефона** — нужно вручную нажать «Запустить помощника».

## 🔒 Безопасность

В коде нет жёстко заданных ключей API. Используется встроенный в Android распознаватель речи Google — аудио отправляется на серверы Google для распознавания. Требуется интернет.
