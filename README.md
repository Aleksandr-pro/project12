# project12 — Помощник AI для Android (v2.0)

Мобильный голосовой помощник на **Android (Kotlin)** с **прямым непрерывным распознаванием русской речи** и **50+ голосовыми командами**:

* **Прямое распознавание речи (по умолчанию)** — не нужно сначала будить помощника громким хлопком или ждать ответа «Да, я слушаю». Просто произносите команду сразу (*«Включи фонарик»*, *«Какая погода в Актобе»*, *«Таймер на 5 минут»*).
* **Два режима на выбор** — прямо в приложении переключатель:
  1. **Прямой режим (ВКЛ по умолчанию)** — мгновенно выполняет любые сказанные команды.
  2. **Режим по слову «Помощник»** — реагирует только если начать фразу со слова *«Помощник» / «Ассистент»* (понимает всю фразу целиком: *«Помощник, открой YouTube»*).
* **Работает в фоне** (Foreground Service с уведомлением и кнопкой быстрой остановки), а также имеет **кнопку разовой голосовой команды** и **текстовый ввод** на главном экране.
* **Автоматическая пауза микрофона на время ответа TTS** — помощник не слушает собственный голос и сразу продолжает распознавание после завершения фразы.

## 📱 Как скачать и установить готовый `.apk` с телефона

### Способ 1 — Прямая ссылка (в один клик, без архива)

1. Нажмите с телефона:  
   `https://github.com/Aleksandr-pro/project12/releases/latest/download/app-debug.apk`  
   *(или откройте `https://github.com/Aleksandr-pro/project12/releases` → нажмите `app-debug.apk` в блоке **Assets**)*.
2. Откройте скачанный `app-debug.apk` → нажмите **«Установить»**.

### Способ 2 — Из вкладки GitHub Actions (Artifacts)

1. Откройте `https://github.com/Aleksandr-pro/project12/actions` → выберите верхний успешный запуск workflow **Build APK** ✅.
2. Внизу страницы в блоке **Artifacts** нажмите **`app-debug-apk`** — скачается архив `app-debug-apk.zip`.
3. Распакуйте `app-debug-apk.zip` в «Файлах» / «Проводнике» на телефоне и установите `app-debug.apk`.

* *«Включи фонарик» / «Включи свет» / «Посвети»* — включает вспышку камеры
* *«Выключи фонарик» / «Выключи свет» / «Погаси фонарик»* — выключает вспышку
