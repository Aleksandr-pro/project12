# project12 — Голосовой помощник для Android

Мобильный голосовой помощник на **Android (Kotlin)**, который:

* работает в **фоновом режиме** (foreground-сервис с уведомлением);
* **постоянно слушает микрофон** и реагирует на звук/фразу пробуждения;
* понимает голосовые команды на **русском языке** (облачное распознавание через системный SpeechRecognizer — Google);
* отвечает голосом (TTS — синтез речи).

## Стек

* Android, Kotlin
* minSdk 24, targetSdk 34
* `SpeechRecognizer` (облачное распознавание речи Google)
* `TextToSpeech` (озвучка ответов)
* `AudioRecord` (мониторинг микрофона в фоне для пробуждения)
* Foreground Service (тип `microphone`), частичный WakeLock

## Как работает

1. Пользователь нажимает «Запустить помощника» — начинается фоновая работа.
2. Сервис мониторит микрофон через `AudioRecord`: при обнаружении звука выше порога — пробуждение.
3. Помощник говорит «Да, я слушаю», записывает команду через `SpeechRecognizer` (русский язык) и исполняет её.
4. Доступные команды (пример): привет / как дела / время / дата / погода / открой настройки / стоп.
5. Помощник возвращается в режим ожидания — всё работает в фоне, даже когда приложение свёрнуто.

## Как собрать

1. Установите [Android Studio](https://developer.android.com/studio).
2. Откройте папку проекта как existing Gradle-проект.
3. Установите Android SDK (API 34) и инструменты сборки через SDK Manager.
4. Соберите: `./gradlew assembleDebug` (или через меню Build → Build Bundle(s) / APK(s)).
5. Установите `.apk` на телефон и запустите.

> **Важно:** в этой среде нет Java/Android SDK, поэтому компиляцию здесь провести нельзя — проект предназначен для сборки в Android Studio на вашем компьютере.

## Права, которые запрашивает приложение

* `RECORD_AUDIO` — доступ к микрофону (обязательный)
* `INTERNET` — облачное распознавание речи
* `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MICROPHONE` — работа в фоне с микрофоном
* `WAKE_LOCK` — удержание процессора активным во время работы
* `POST_NOTIFICATIONS` — уведомление о фоновой работе (Android 13+)

## Настройка порога срабатывания

Порог звука для пробуждения задаётся в `WakeWordMonitor.kt`:

```kotlin
private val energyThreshold: Double = 1200.0
```

Если помощник не реащивается на голос — понизьте порог; если срабатывает на любой шум — повысьте. Подбор ведётся экспериментально под конкретное устройство и окружение.

## Безопасность

Код не содержит жёстко заданных ключей API — используется встроенный в Android распознаватель речи Google. Интернет нужен для передачи аудио на распознавание.
