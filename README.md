# project12 — Голосовой помощник для Android

Мобильный голосовой помощник на **Android (Kotlin)**, который:

* работает в **фоновом режиме** (фоновый сервис с уведомлением);
* **постоянно слушает микрофон** и будится при звуке голоса;
* понимает голосовые команды на **русском языке** (распознавание через системный SpeechRecognizer — Google);
* отвечает голосом (TTS — синтез речи).

---

## ⚠️ Важное предупреждение перед скачиванием

В репозитории лежит **исходный код** (файлы `.kt`, манифест, настройки Gradle), а не готовое приложение.

**Нельзя** скачать ZIP,rename его в `.apk` и установить на телефон. Так не работает: `.apk` — это уже скомпилированное приложение, а ZIP из репозитория — это просто текстовые файлы с кодом. Телефон не сможет его запустить.

Чтобы получить настоящий `.apk`, нужно **скомпилировать проект** на компьютере с **Android Studio** (или другим инструментом сборки Android).

## 🛠 Как получить готовый .apk (требуется компьютер)

### Шаг 1. Установите Android Studio

1. Скачайте бесплатно: [developer.android.com/studio](https://developer.android.com/studio)
2. Установите, следуя инструкциям установщика.
3. При первом запуске согласитесь установить **Android SDK** и **Android SDK Build-Tools**.

### Шаг 2. Откройте проект

1. Запустите Android Studio.
2. Нажмите **Open** и выберите папку, куда извлекли ZIP-архив.
3. Дождитесь, пока Gradle загрузит зависимости (может занять несколько минут, нужен интернет).

### Шаг 3. Соберите APK

1. В меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
2. Дождитесь завершения сборки (внизу появится уведомление).
3. Готовый файл находится здесь:  
   `app/build/outputs/apk/debug/app-debug.apk`

### Шаг 4. Перенесите APK на телефон

* Через USB-кабель (перетащите файл в папку Download)
* Через Telegram, WhatsApp, Google Drive, Bluetooth — любым удобным способом

## 📱 Как установить APK на телефон

1. На телефоне откройте скачанный файл `app-debug.apk` (обычно в папке **Загрузки**).
2. Если система спросит «Установка неизвестных приложений» — разрешите для браузера/файлового менеджера, через который открываете APK.
3. Нажмите **Установить**, затем **Готово**.
4. При первом запуске приложение запросит разрешение на **미крофон** и **интернет** — обязательно разрешите, иначе помощник не заработает.

## 🎤 Как пользоваться помощником

1. Откройте приложение «Помощник AI».
2. Нажмите **«Запустить помощника»**.
3. Появится уведомление «Помощник работает» — теперь он слушает в фоне, даже если свернуть приложение.
4. Громко скажите ключевую фразу (по умолчанию любой звук выше порога будит помощника).
5. Помощник ответит «Да, я слушаю» — называйте команду.
6. Доступные команды (пример):
   * «привет» / «здравствуй» — приветствие
   * «как дела» — ответ о состоянии
   * «время» — текущее время
   * «дата» — текущая дата
   * «погода» — информация (заглушка)
   * «открой настройки» — откроет системные настройки
   * «стоп» / «выключись» — завершить работу помощника

## 🔊 Настройка чувствительности к голосу

Порог срабатывания задаётся в файле `WakeWordMonitor.kt`:

```kotlin
private val energyThreshold: Double = 1200.0
```

* Если помощник **не слышит** ваш голос — **понизьте** значение (например, до `800.0`).
* Если срабатывает на **любой шум** — **повысьте** значение (например, до `2000.0`).

После изменения нужно снова собрать APK в Android Studio.

## ❌ Возможные ошибки и как их исправить

| Ошибка | Причина | Решение |
|--------|---------|---------|
| «Приложение не установлено» | APK повреждён или не подходит под версию Android | Соберите APK заново в Android Studio. Убедитесь, что на телефоне Android 7.0 (API 24) или новее |
| «Установка неизвестных приложений заблокирована» | Защита системы Android | Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → ваш файловый менеджер → Разрешить |
| Помощник не реагирует на голос | Нет разрешения на микрофон или порог срабатывания слишком высок | Дайте разрешение на микрофон в настройках телефона. Пoniзьте `energyThreshold` в коде и пересоберите |
| Помощник не говорит (нет голоса) | TTS не инициализирован или нет языковых данных | На телефоне: Настройки → Язык и ввод → Текст в речь → установите русский язык. Перезапустите приложение |
| Распознавание не работает | Нет интернета или SpeechRecognizer недоступен | Включите мобильный интернет или Wi-Fi. Убедитесь, что на телефоне установлены сервисы Google |
| Приложение закрывается при свертывании | Система убивает фоновый процесс | Настройки → Батарея → Помощник AI → «Не оптимизировать» или «Без ограничений». Разрешите работу в фоне |
| Уведомление «Помощник работает» не исчезает | Это нормально — foreground-сервис | Это признак того, что помощник работает в фоне. Чтобы остановить, нажмите «Остановить помощника» в приложении |
| «Распознаватель речи недоступен» | На устройстве нет Google SpeechRecognizer | На некоторых прошивках (особенно китайских) нет сервисов Google. Помощник не заработает без них |
| APK не устанавливается — «Не удалось 분석ровать пакет» | Файл не является APK (например, переименован ZIP) | Не переименовывайте ZIP в APK. Используйте только настоящий `app-debug.apk` из сборки Android Studio |

## 🧩 Что не входит в этот проект (пропуски)

Ниже перечислено, что **ещё не реализовано** и может потребоваться доработке:

1. **Точная фраза пробуждения** — сейчас assistant будится на любой звук выше порога, а не на конкретное слово («Помощник»). Для точного ключевого слова нужна отдельная библиотека (например, Porcupine или Precise).
2. **Онлайн-погода** — команда «погода» показывает только заглушку. Для реальной погоды нужно подключить API (OpenWeather, Яндекс.Погода и т.д.).
3. **Офлайн-режим** — распознавание требует интернета. Без сети assistant не услышит команду.
4. **Настройка в приложении** — порог чувствительности и список команд меняются только в коде, без интерфейса настроек.
5. **Автозапуск при включении телефона** — сейчас нужно вручную нажать «Запустить помощника» после перезагрузки.

## 🔒 Безопасность и конфиденциальность

* В коде нет жёстко заданных ключей API.
* Используется встроенный в Android распознаватель речи Google — аудио отправляется на серверы Google для распознавания.
* Для работы требуется интернет.
* Микрофон используется только когда приложение запущено и работает в фоне.
