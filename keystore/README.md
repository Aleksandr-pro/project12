# Ключ подписи Нелли AI

Файл: `nelly.p12` (PKCS12, RSA 2048, срок 30 лет)

| Параметр | Значение |
|---|---|
| storePassword | `nelly2026` |
| keyAlias | `nelly` |
| keyPassword | `nelly2026` |
| storeType | `PKCS12` |

## Зачем он нужен

Android разрешает устанавливать новую версию **поверх** старой только тогда, когда обе подписаны
**одним и тем же ключом**. Раньше каждая сборка на GitHub Actions генерировала случайный
отладочный ключ, поэтому обновление падало с ошибкой «Приложение не установлено» и требовало
удаления старой версии.

Теперь ключ лежит в репозитории, и все сборки подписываются одинаково — обновления ставятся
как обычное обновление приложения, данные и настройки сохраняются.

## Важно

* **Не удаляйте и не пересоздавайте** этот файл: новый ключ = невозможность обновиться без удаления.
* Ключ самоподписанный и предназначен только для личной сборки. Для публикации в Google Play
  нужен отдельный ключ, хранящийся в секрете.
